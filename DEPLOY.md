# Задачник SRM — как выкладывать

База: Supabase-проект `qlyqgltoumxixteerqak` (новая). Старую базу не трогаем.

## Обычный режим (сейчас, бесплатно)
Timeweb App Platform → «Задачник SRM» (HTML/CSS/JS) → Настройки → выбрать последний коммит → «Сохранить» → «Запустить».
Приложение обращается к базе напрямую (`*.supabase.co`).

## Режим «без VPN» (по желанию, нужен Node-сервер)
`server.js` раздаёт файлы и пропускает запросы к базе через `/sb`.
Запуск: `node server.js` (порт из `PORT`, по умолчанию 8080), проверка: `/healthz`.
Когда сайт отдаёт `server.js`, он сам включает посредника (метка `sb-proxy` в index.html).

## Перед выкладкой
Прогнать автотест на тестовых данных (заглушка), проверить вход владельца и сотрудника.
